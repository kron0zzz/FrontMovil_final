
# MakandApp
Este proyecto corresponde al frontend móvil de Makand. Su propósito es permitir a los usuarios interactuar con la plataforma desde dispositivos móviles 


## Tecnologías usadas
- Flutter 
- Dart


## Instalación y ejecución
#### 1. Clonar este repositorio
    git clone https://github.com/kron0zzz/FrontMovil_final.git
#### 2. Entrar al proyecto
    cd FrontMovil_final
#### 3. Ejecutar el proyecto en Chrome
    flutter run -d Chrome
